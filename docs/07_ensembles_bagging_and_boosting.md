# Module 07: Ensembles (Bagging and Boosting)

## Overview
How aggregation and sequential weak learners manage the tradeoff: Bootstrapping and variance reduction in Random Forests versus bias reduction in Gradient Boosting Machines (GBM) and Histogram-based boosting.
